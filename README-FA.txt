روزِ من — مرحلهٔ ۳: برنامه‌ریز شمسی + اعلان آفلاین اندروید
=======================================================

خروجی این بسته «پروژهٔ کامل اندروید» و فایل‌های وب است، نه APK ازپیش‌ساخته.
برای تبدیل پروژه به فایل APK به Android SDK و Gradle نیاز است. فایل‌های آمادهٔ
ساخت خودکار با GitHub Actions نیز داخل همین بسته گذاشته شده‌اند.

ویژگی‌های مرحلهٔ سوم
------------------
۱. حفظ تمام برنامه‌های هفتگی و یادآوری‌های مرحلهٔ ۲ و نمایش شمسی.
۲. برای هر برنامهٔ هفتگی: اعلان خاموش/ابتدای کار/۵، ۱۵، ۳۰، ۶۰ دقیقه زودتر.
۳. برای یادآوری‌ها: فعال/غیرفعال‌کردن اعلان در زمان تعیین‌شده.
۴. تکرار اعلان بدون تکرار، هفتگی، ماهانهٔ شمسی، سالانهٔ شمسی.
۵. برای روزهای نامعتبر در ماه تکرار، آخرین روز ماه جایگزین می‌شود.
۶. در نسخهٔ اندروید: AlarmManager بومی با قابلیت کار بدون اینترنت و با بسته‌بودن برنامه.
۷. اعلان در نوار اعلان با اکشن «مشاهده شد» و صندوق اعلان‌های مشاهده‌نشدهٔ داخلی.
۸. داده‌ها و تنظیمات اعلان‌ها فقط روی خود دستگاه ذخیره می‌شوند.
۹. با راه‌اندازی مجدد گوشی، زمان‌بندی‌های آینده دوباره برقرار می‌شوند؛ تغییر ساعت
   و منطقهٔ زمانی نیز موجب زمان‌بندی مجدد می‌شود.
۱۰. ورود/خروج پشتیبان JSON نسخه‌های ۱، ۲ و ۳. فایل‌های قدیمی وارد نسخهٔ جدید می‌شوند.

نصب نسخهٔ اندروید از طریق GitHub Actions (بدون Android Studio)
--------------------------------------------------------------
۱. از داده‌های نسخهٔ قبلی در Chrome یا برنامهٔ قبلی خروجی پشتیبان JSON بگیر.
۲. همین ZIP را از حالت فشرده خارج کن.
۳. در GitHub یک repository جدید بساز.
۴. محتویات ریشهٔ ZIP را (همهٔ فایل‌ها، پوشهٔ android و پوشهٔ مخفی .github)
   در ریشهٔ repository آپلود و commit کن.
   حتماً پوشهٔ .github/workflows/build-apk.yml هم در مخزن باشد.
۵. به تب Actions برو؛ گردش کار «Build Rooz-e-Man Android APK» را انتخاب کن.
۶. «Run workflow» را اجرا کن. پس از موفقیتِ اجرای ساخت، در قسمت Artifacts فایل
   «rooz-e-man-v3-debug-apk» را دریافت و ZIP کوچکِ آن را باز کن.
۷. فایل app-debug.apk را به گوشی اندرویدی منتقل و نصب کن. ممکن است لازم باشد
   مجوز «نصب برنامه از این منبع» را در اندروید فعال کنی.
۸. برنامه «روزِ من» را باز کن، دکمهٔ «فعال‌سازی مجوز اعلان و هشدار» را بزن و
   مجوز Notifications و دسترسی ویژهٔ Alarms & reminders را فعال کن.
۹. برای کنترل نوتیفیکیشن، دکمهٔ «ارسال اعلان آزمایشی» را بزن.
۱۰. از بخش بازیابی پشتیبان در اپ نصب‌شده، فایل پشتیبان مرحلهٔ قبلی را وارد کن.

نصب به کمک Android Studio
--------------------------
- پوشهٔ android را در Android Studio باز کن.
- اجازه بده Gradle Sync انجام شود و Android SDK API 35 و Java 17 در دسترس باشند.
- از Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی debug apk بساز.
- مسیر خروجی: android/app/build/outputs/apk/debug/app-debug.apk

گزینهٔ نسخهٔ وب (فاقد اعلان آفلاین)
----------------------------------
مانند نسخه‌های قبل، می‌توان فایل‌های ریشهٔ پروژه مانند index.html، app.js،
styles.css، sw.js و پوشهٔ icons را در همان آدرس HTTPS قبلی جایگزین کرد.
تقویم و تنظیم تکرارها در مرورگر کار می‌کند؛ اما بدون اپ بومی، رسیدن اعلان
در ساعت دقیق هنگام بسته بودن مرورگر یا آفلاین بودن گوشی تضمین نمی‌شود.

حفظ اطلاعات هنگام مهاجرت
-------------------------
- برای ارتقای نسخهٔ وب روی همان دامنه/نشانی قبلی، داده‌های IndexedDB حفظ می‌شوند.
- اما اپ بومی اندروید نسبت به Chrome حافظهٔ جدا دارد؛ انتقال داده خودکار نیست.
- قبل از نصب حتماً یک پشتیبان از نسخهٔ قبلی بگیر و در APK جدید وارد کن.
- هنگام بازیابی نسخهٔ ۱ فقط برنامه‌های هفتگی جایگزین می‌شوند.
- بازیابی نسخه‌های ۲ و ۳ تمام برنامه‌ها و یادآوری‌ها را جایگزین می‌کند.
- فایل پشتیبان را امن نگهداری کن؛ ممکن است دل‌نوشته/یادآوری‌های خصوصی داشته باشد.

محدودیت‌های مهم اندروید
-----------------------
- از Android 13 اجازهٔ نمایش اعلان لازم است.
- از Android 12 برای زمان دقیق ممکن است مجوز ویژهٔ «Alarms & reminders» لازم باشد.
  بدون آن از هشدار غیر دقیق استفاده می‌کنیم که احتمال تأخیر دارد.
- از Android 14 حتی اعلان ongoing در برخی شرایط قابل پاک‌کردن از پنل اعلان است.
  نمی‌توان نوار اعلانِ سیستم‌عامل را کاملاً غیرقابل‌حذف کرد.
  با این حال تا زدن دکمهٔ «مشاهده شد»، رکورد اعلان در «صندوق اعلان‌ها» باقی می‌ماند.
- Force stop از تنظیمات گوشی، خاموش بودن گوشی در موعد، خاموش‌کردن اعلان‌ها، و بعضی
  محدودیت‌های شدید سازندگان گوشی می‌توانند هشدارها را به تأخیر بیندازند یا متوقف کنند.
- «تکرار» در مرحلهٔ سوم به اعلان مربوط است، نه کپی خودکار رکورد برنامهٔ هفتگی.
- حذف یک رکورد یا انجام‌شده علامت زدن آن، اعلان‌های آیندهٔ آن را لغو می‌کند.
- پس از فشار دادن دکمهٔ «مشاهده شد» یک اعلان، تکرارهای آینده همچنان فعال می‌مانند.
- نسخهٔ اندروید حداقل به Android 8 (API 26) نیاز دارد.
- خروجی GitHub Actions از نوع debug APK است. هر اجرای مستقل می‌تواند با کلیدِ امضای متفاوتی
  ساخته شود؛ برای نصب نسخهٔ بعدی، پیش از حذف نسخهٔ قبلی از اطلاعات پشتیبان بگیر.
  برای ارتقای بدون حذف داده در آینده لازم است APKهای بعدی با کلید امضای ثابت ساخته شوند.
- در این محیط APK ساخته/روی گوشی آزمایش نشده است؛ برای اطمینان باید نتیجهٔ
  GitHub Actions و آزمایش عملی روی گوشی را بررسی کنید.
